# Registry: platform

## What this registry holds

Platform-level components, services, and infrastructure items that are shared across
products. Each entry describes the platform component, its owner, interface contract, and
SLA tier.

## File format

One YAML file per item, named `<id>.yaml`.
Example: `plat-event-bus.yaml`, `plat-identity.yaml`

## Schema reference

`schemas/registry/platform.v1.schema.json`
