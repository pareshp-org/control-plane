# Registry: tools

## What this registry holds

Approved tools and integrations used within the Multi-Product Engineering OS — build
tools, CI/CD systems, observability platforms, developer productivity tools. Each entry
records the tool ID, category, approval status, and any constraints on use.

## File format

One YAML file per item, named `<id>.yaml`.
Example: `tool-github-actions.yaml`, `tool-datadog.yaml`
