# Registry: economics

## What this registry holds

Economics registry items — pricing models, cost allocations, revenue sharing rules, and
unit economics definitions that govern how value flows between products and the platform
within the Multi-Product Engineering OS.

## File format

One YAML file per item, named `<id>.yaml`.
Example: `econ-platform-cost-share.yaml`, `econ-lane-budget.yaml`
