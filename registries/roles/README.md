# Registry: roles

## What this registry holds

Canonical role definitions within the Multi-Product Engineering OS — the named seat types
(Integrator, Lane Lead, Contributor, etc.), their authority level, and the governance rules
that govern each role.

## File format

One YAML file per item, named `<id>.yaml`.
Example: `integrator.yaml`, `lane-lead.yaml`, `contributor.yaml`

## Schema reference

`schemas/registry/roles.v1.schema.json`
