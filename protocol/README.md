# protocol/
Cross-cutting protocol documents for the Multi-Product Engineering OS.
These documents apply across all 5 lanes (L0-L5) and define shared processes.

## Files
Most .md files describe a cross-cutting process or protocol and are authoritative reference documents — do not duplicate content in lane files.
Exceptions: 99-WALKTHROUGH.md is a diagnostic walkthrough (Status: diagnostic, not normative) and _98-DEEP-REVIEW.md is an audit report of defects found in this directory; neither is authoritative.
